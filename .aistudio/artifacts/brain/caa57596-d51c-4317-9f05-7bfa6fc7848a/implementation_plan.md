# Cyberpunk Core: Neon Clicker & Automation

Комплексный кликер в темной неоновой стилистике киберпанка с кулдаун-ядром, прямоугольными вкладками-подокнами, сбалансированной прокачкой, системой престижа от 1 миллиона поинтов, многопоточной автоматикой и гибким сохранением.

> [!IMPORTANT]
> **Подтвержденные решения из опроса (Фаза 1):**
> - **Стиль**: Темный киберпанк с глубоким фоном, неоновым свечением (cyan/magenta/amber) и частицами клика.
> - **Автоматика**: Открывается через улучшение в Престиже. Включает 5 автономных модулей: `Autoclicker` (начальный цикл 10 сек) и `AutoUpg 1–4` (начальный цикл 60 сек каждый), покупаемые и прокачиваемые за Престиж-поинты.
> - **Звук**: Процедурный синтезатор Web Audio API (без внешних файлов) с кнопкой включения/выключения звука и чистыми футуристическими щелчками/сигналами.

---

### 1. Overview & Core Concept

- **Игровой цикл**:
  1. **Клик по Ядру**: Игрок кликает по центральному квантовому кругу и получает базовые поинты и клики. Каждый клик повышает множитель на `+0.01x` за единицу кликов.
  2. **Кулдаун**: Базовый кулдаун круга — `5.0 секунд`. Вокруг ядра отображается круговой SVG-таймер зарядки.
  3. **Прокачка (Улучшения)**: В правом выдвижном меню за поинты покупаются:
     - `+1` к базовым получаемым поинтам
     - `+0.2` к получаемым кликам за клик
     - `-0.1s` к кулдауну круга (вплоть до сотых долей секунды)
     - `+0.1x` к глобальному множителю поинтов
  4. **Престиж (1,000,000 поинтов)**: При накоплении 1 миллиона текущих поинтов замок спадает. Игрок может совершить Престиж, сбросив поинты и обычные улучшения в обмен на Престиж-поинты (PP).
  5. **Автоматика**: За PP в Престиже разблокируется вкладка Автоматики с таймерами автоклика и независимой автопокупки каждого из 4-х улучшений.
  6. **Настройки и Сохранения**: Ручное сохранение, автосохранение раз в 10 секунд, экспорт/импорт строки сохранения (Base64/JSON) и сброс игры.

### 2. User Experience & Visual Design

#### Layout & Navigation
- **Центральная арена**:
  - Большое интерактивное ядро (круг с неоновым свечением, реакцией на наведение, пульсацией при готовности и SVG-кольцом перезарядки).
  - Числовые плашки текущих ресурсов в верхней части экрана: Поинты, Клики, Текущий множитель (`1 + Clicks*0.01 + Bonus`), Престиж-поинты.
  - Анимированные всплывающие числа (+Points, +Clicks) и радиальные импульсы при успешном клике.
- **Правое раскрываемое окно (Панель управления)**:
  - Кнопка разворачивания/сворачивания с индикатором доступных улучшений.
  - В развернутом виде: слева вертикальный ряд стильных прямоугольных вкладок-подокон:
    - `Улучшения` (Upgrades) — доступно сразу;
    - `Престиж 🔒` (Prestige) — замок до 1 000 000 поинтов, прогресс-бар до разблокировки;
    - `Автоматика 🔒` (Automation) — замок до покупки улучшения в Престиже;
    - `Настройки` (Settings) — всегда доступны.
  - Справа от списка вкладок — активная рабочая область выбранного подокна с плавными переходами.

#### Visual Tokens & Atmosphere
- **Canvas / Фон**: `#07090E` с тонкой кибернетической сеткой и легкими фоновыми пылинками.
- **Панели и подокна**: `#0F141F` с акцентными границами `border-cyan-500/20` и мягким неоновым свечением.
- **Цветовая триада**:
  - Неоновый Циан (`#00F2FE` / `#00C2CB`): основные действия, ядро, поинты.
  - Электрический Пурпур (`#C084FC` / `#A855F7`): клики и множители.
  - Золотой / Янтарный (`#F59E0B` / `#FBBF24`): престиж и автоматика.
- **Типографика**: Четкий гротеск для заголовков и `tabular-nums font-mono` для всех числовых счетчиков, чтобы исключить дрожание текста при росте чисел.

### 3. Key Product Decisions & Trade-Offs

- **Формула дохода за клик**:
  $$\text{PointsPerClick} = \text{basePoints} \times (1 + \text{clicks} \times 0.01) \times (1 + \text{multiplierBonus}) \times \text{prestigeBonus}$$
  Это гарантирует, что каждая сотня кликов удваивает ценность последующих кликов, формируя удовлетворяющий экспоненциальный прогресс.
- **Баланс цен и достижимость 1М поинтов**:
  - Базовые стоимости:
    - Улучшение 1 (+1 Point): базовая цена 10, множитель роста $1.15$
    - Улучшение 2 (+0.2 Clicks): базовая цена 25, множитель роста $1.18$
    - Улучшение 3 (-0.1s Cooldown): базовая цена 75, множитель роста $1.35$ (с ограничением минимального кулдауна до 0.2 сек)
    - Улучшение 4 (+0.1x Multiplier): базовая цена 150, множитель роста $1.25$
  - За ~40-60 минут активной игры игрок достигает 1 000 000 поинтов.
- **Престиж и Валюта (Prestige Points - PP)**:
  - При первом престиже на 1M дается 1-3 PP в зависимости от накопленных поинтов ($\text{PP} = \lfloor \sqrt{\text{points} / 1\,000\,000} \rfloor$).
  - В дереве Престижа:
    - *«Разблокировать модуль автоматики»* (1 PP) — открывает доступ к подуровню Автоматика.
    - *«Квантовый импульс»* (+50% к поинтам за уровень, 1 PP).
    - *«Ускоренный пуск»* (-0.5s к стартовому кулдауну, 2 PP).
- **Многопоточная Автоматика (Вкладка «Автоматика»)**:
  - `Autoclicker`: автономный таймер (10 сек). При срабатывании активирует ядро, если оно не на кулдауне. Прокачка за PP снижает таймер до 1 сек.
  - `AutoUpg 1–4`: автономные независимые таймеры (базово 60 сек). При срабатывании автоматически покупают соответствующее улучшение, если хватает поинтов. Прокачка за PP снижает время цикла (60s -> 45s -> 30s -> 15s -> 5s).
- **Web Audio Синтез**:
  - Реализация на нативном `AudioContext` браузера без тяжелых аудиобиблиотек:
    - Клик: короткий затухающий синусоидальный импульс с частотной модуляцией (880Hz -> 220Hz).
    - Ошибка клика на кулдауне: глухой басовый клик (120Hz).
    - Завершение кулдауна: тихий кристальный сигнал готовности.
    - Покупка: мажорное двузвучие (до-ми).
    - Престиж: восходящий свип с фильтром.

#### State Structure
```typescript
interface GameState {
  points: number;
  totalPointsEarned: number;
  clicks: number;
  cooldownRemaining: number; // in seconds, updated per tick
  prestigePoints: number;
  prestigeCount: number;
  automationUnlocked: boolean;
  
  // Base Upgrades
  upgrades: {
    pointsBonus: number;   // Level of +1 points
    clicksBonus: number;   // Level of +0.2 clicks
    cooldownReduction: number; // Level of -0.1s cooldown
    multiplierBonus: number;   // Level of +0.1x
  };
  
  // Prestige Upgrades
  prestigeUpgrades: {
    quantumImpulse: number; // +50% points per level
    fastStart: number;      // -0.5s starting cooldown
  };

  // Automation Modules (Timers & Levels)
  automation: {
    autoclicker: { level: number; interval: number; timer: number; enabled: boolean };
    autoUpg1: { level: number; interval: number; timer: number; enabled: boolean };
    autoUpg2: { level: number; interval: number; timer: number; enabled: boolean };
    autoUpg3: { level: number; interval: number; timer: number; enabled: boolean };
    autoUpg4: { level: number; interval: number; timer: number; enabled: boolean };
  };

  settings: {
    soundEnabled: boolean;
    autosaveEnabled: boolean;
  };
  lastSavedAt: number;
}
```

### План проверки сборки
1. Проверка компиляции `compile_applet` и линтинга `lint_applet`.
2. Тестирование формул и кликов:
   - Клик начисляет верные поинты и клики.
   - 5-секундный таймер корректно перезаряжается с визуальным заполнением кольца.
   - Покупка улучшений корректно списывает поинты и пересчитывает кулдаун и множитель.
3. Проверка замков:
   - Престиж заблокирован до 1,000,000 поинтов и разблокируется при достижении цели.
   - Автоматика заблокирована до покупки улучшения в Престиже.
   - Таймеры автоматики (10 сек для клика, 60 сек для автопокупки) тикают и отображают прогресс.
4. Проверка сохранения:
   - Автосохранение в `localStorage`.
   - Экспорт в буфер обмена в виде закодированной строки.
   - Импорт строки и восстановление состояния.
   - Сброс с подтверждением.
